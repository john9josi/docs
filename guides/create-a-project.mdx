## Before you start

- You're signed in. See the [Quickstart](/quickstart).
- You have permission to create projects in your workspace.

<Tabs>
  <Tab title="Web app">
    <Steps>
      <Step title="Open Projects">
        In [app.tryulysses.com](https://app.tryulysses.com), go to **Projects**.
      </Step>
      <Step title="Start a new project">
        Select **New project**.
      </Step>
      <Step title="Choose capital project or program">
        Select whether this is a capital project or a service program.
      </Step>
      <Step title="Add details">
        Enter the name, description, start and end dates, department, budget, kind, location, EERP/MUNIS number, and URL.
      </Step>
      <Step title="Set funding status">
        Select the current funding status: fully funded, partially funded, or unfunded. Include how it's funded, or how you'd like to fund it.
      </Step>
      <Step title="Review and create">
        Review your entries and select **Create**. Once created, you can add identifiers, update its status, or put it on hold.
      </Step>
    </Steps>
  </Tab>
  <Tab title="CLI">
    You also need `project:write` permission on the tenant.

    <Steps>
      <Step title="Confirm your workspace">
        ```bash
        ulysses-cli --output json auth whoami
        ```

        To switch workspaces, run `auth contexts`, then `auth use <tenant-id>`.
      </Step>
      <Step title="Create the project">
        ```bash
        ulysses-cli --output json projects create \
          --title "Bridge retrofit" \
          --postal-code 94901 \
          --project-type infrastructure \
          --summary "Seismic work"
        ```

        | Flag | Notes |
        | --- | --- |
        | `--title` | Required. |
        | `--postal-code` | Required. A US ZIP code. Ulysses derives the state from it. |
        | `--project-type` | Required. One of `infrastructure`, `childcare`, `workforce_development`, `housing`, `education`, `health`, `environment`, `arts_culture`, `public_safety`, or `other`. |
        | `--summary` | Optional. |

        The project is added to your workspace's organization. The response includes `projectId`, `created: true`, and a `url` you can open in the web app.
      </Step>
      <Step title="Update fields (optional)">
        `projects update` changes only the flags you pass. The title and project type can't be changed after creation.

        ```bash
        ulysses-cli --output json projects update <project-id> --summary "New description"
        ulysses-cli --output json projects update <project-id> --federal-number FED-1001
        ulysses-cli --output json projects update <project-id> --hold --hold-reason "Waiting on permits"
        ```

        - `--summary-mode append` adds to the summary instead of replacing it.
        - `--release-hold` clears a hold.
        - Pass an empty value to `--federal-number`, `--state-award-number`, or `--cip-number` to clear it.
      </Step>
    </Steps>
  </Tab>
</Tabs>
