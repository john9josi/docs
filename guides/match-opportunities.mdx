---
title: "Match opportunities"
description: "See which funding opportunities Ulysses has matched to a project."
---

Ulysses scores funding opportunities against each project or program and stores the results.

## Before you start

- You're signed in. See the [Quickstart](/quickstart).

<Tabs>
  <Tab title="Web app">
    <Steps>
      <Step title="Open the project">
        In [app.tryulysses.com](https://app.tryulysses.com), go to **Projects** and open the one you want. You can also find projects from **Discover**.
      </Step>
      <Step title="View matched opportunities">
        Open the **Opportunities** tab on the project. Each match shows a score and the reasons behind it.

        <Note>
          No matches yet? The project hasn't been scored. This isn't an error — check back after the next scoring run.
        </Note>
      </Step>
      <Step title="Open an opportunity">
        Select a match to see the full NOFO and decide whether to pursue it. You can also browse every opportunity from **Discover**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="CLI">
    This reads stored matches. It doesn't rescore.

    <Steps>
      <Step title="Find the project">
        ```bash
        ulysses-cli --output json projects list --limit 50
        ```

        Copy the `projectId` of the project you want.
      </Step>
      <Step title="Show its matches">
        ```bash
        ulysses-cli --output json matches show <project-id>
        ```

        The result includes `projectId`, `scoredAt`, and a list of `matches`. `--limit` caps the number of matches returned (default 50).

        | Field | Meaning |
        | --- | --- |
        | `opportunityId` | The ID to pass to `opportunities show`. |
        | `opportunityName` | The opportunity's name. |
        | `score` | Numeric match score. |
        | `band` | `Strong`, `Moderate`, or `Weak`. |
        | `rationale` | Why it matched. |
        | `factors` | The factors behind the score. |

        <Note>
          If `matches` is empty and `scoredAt` is null, the project hasn't been scored yet. This isn't an error.
        </Note>
      </Step>
      <Step title="Open an opportunity">
        ```bash
        ulysses-cli --output json opportunities show <opportunity-id>
        ulysses-cli --output json links resolve opportunity <opportunity-id>
        ```

        Open `result.url` to view the opportunity in the web app.
      </Step>
    </Steps>
  </Tab>
</Tabs>
