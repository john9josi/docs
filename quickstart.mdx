Takes about 5 minutes.

## Before you start

- Find an invitation to your agency's workspace in your email inbox. If you don't have one, ask your workspace admin or email [support@tryulysses.com](mailto:support@tryulysses.com).
- Ensure you have macOS, Linux, or Windows with network access to `app.tryulysses.com` and, for the CLI, `install.tryulysses.com`.

New to Ulysses? Use the **web app**. Writing scripts or working with an AI agent? Use the **CLI**.

<Tabs>
  <Tab title="Web app">
    <Steps>
      <Step title="Sign in">
        Open [app.tryulysses.com](https://app.tryulysses.com) and sign in with your organization's identity provider. If your agency doesn't use single sign-on, sign in with the email and password from your invitation.
      </Step>
      <Step title="Check your workspace">
        If your email is associated with more than one workspace, you can switch between them in the product. What you can see depends on your role in the active workspace.

        <Note>
          Don't see your agency's workspace? Make sure you accepted the invitation email, then email [support@tryulysses.com](mailto:support@tryulysses.com).
        </Note>
      </Step>
      <Step title="Open a project">
        Go to **Projects** and open a project or program. You'll see its department, budget, dates, links, funding status, and capital stack.
      </Step>
      <Step title="Ask a question">
        Ask Ulysses a question about your portfolio, such as the funding status of a project. A good answer cites the project or award it's drawing from.
      </Step>
    </Steps>

    You're set up. Continue to [Next steps](#next-steps).
  </Tab>
  <Tab title="CLI">
    Use the CLI for scripts, automation, and AI agents. The installer adds [uv](https://docs.astral.sh/uv/) if it's missing.

    <Steps>
      <Step title="Install">
        ```bash
        curl -fsSL https://install.tryulysses.com/cli | sh
        ulysses-cli --version
        ```

        The installer downloads the signed release from `install.tryulysses.com`, verifies it, and installs `ulysses-cli`.
      </Step>
      <Step title="Sign in">
        ```bash
        ulysses-cli auth login
        ulysses-cli auth whoami
        ```

        Finish the device login in your browser. Tokens are stored in your OS keychain when available.

        `auth whoami` returns something like:

        ```json
        {
          "ok": true,
          "result": {
            "email": "you@example.com",
            "tenantId": "tnt_9f2a1c",
            "tenantName": "City of Example",
            "role": "member"
          }
        }
        ```

        <Note>
          Sign-in failing, or no tenant showing up? Confirm you accepted your invitation email, then try `ulysses-cli auth login` again.
        </Note>
      </Step>
      <Step title="Choose a workspace">
        If you belong to more than one workspace, list them and pick one:

        ```bash
        ulysses-cli auth contexts
        ulysses-cli auth use <tenant-id>
        ```
      </Step>
      <Step title="List your projects">
        ```bash
        ulysses-cli projects list
        ```

        ```json
        {
          "ok": true,
          "result": [
            { "projectId": "prj_4k2j1", "title": "Bridge retrofit", "projectType": "infrastructure" },
            { "projectId": "prj_7m3p9", "title": "Homelessness services", "projectType": "health" }
          ]
        }
        ```

        An empty `result` list is a successful read. It just means no projects exist in this workspace yet. Run `ulysses-cli` on its own to see every command.
      </Step>
    </Steps>

    You're set up. Continue to [Next steps](#next-steps).
  </Tab>
</Tabs>
